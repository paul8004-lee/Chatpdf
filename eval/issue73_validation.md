# Issue #73 검증 기록

기준 develop 커밋은 `0df5630`, 작업 브랜치는 `feature/report_library_#73`입니다.

## 검증 방법

- 오프라인 회귀: `python -m unittest discover -q`. 기존 테스트와 신규 카탈로그·라우팅·문서별 근거 확보·근거 누락·요소 보존 테스트를 실행합니다. 신규 테스트는 초기 관광/수출/유가 자료와 다른 가상 태양광/물류/농업 보고서를 생성해 사용합니다.
- 실제 비교: `python eval/eval_issue73.py --live --output eval/results_issue73_policy.jsonl`. 기존 `.env` 키를 사용하고, 이전/이후 코드가 같은 텍스트 전용 인덱스를 공유합니다. 문서 찾기·사실·비교·근거 없는 질문 각 1개입니다. 응답 원문·토큰·시간을 JSONL에, 단계 로그를 별도 events JSONL에 누적합니다. 로컬 산출물은 Git에서 제외합니다.
- 비용 필드는 입력 100만 토큰당 $0.15, 출력 $0.60라는 실험 가정으로 계산한 LLM 추정액입니다. 현재 청구 요율 검증이나 전체 비용 계산이 아니며, 임베딩 비용과 캐시 입력 할인은 반영하지 않습니다.

## 해석 범위

문서 목록 검색은 LLM을 호출하지 않습니다. 날짜와 주제를 함께 제시하면 두 조건의 교집합을 사용합니다. 비교는 선택된 문서마다 별도로 후보를 보충하고, 정책 과제 질문은 시사점·대응 방안 검색을 추가합니다. 검색 근거가 누락된 문서는 최종 답변에 표시합니다.

실제 비교 표본은 4문항이므로 일반적인 정확도나 응답률 수치로 해석할 수 없습니다. 초기 비교에서는 두 문서 모두 인용했으나 유가 보고서의 구체적인 조달·공급망 권고 대신 개요만 제시했습니다. 이 관찰을 근거로 문서별 정책 과제 검색과 시사점 절의 근거 보존을 보완했습니다. 최종 비교 재실행(`results_issue73_sections.jsonl`)에서는 유가 보고서 PDF p.11의 유가 기준 현실화·조달 전략 재설계를 답변에 포함했습니다. 답변 내용은 자동 채점하지 않으며 기록된 응답과 PDF 원문을 대조해야 합니다.

텍스트 전용 실험은 표·이미지 요약 품질과 전체 등록 비용을 검증하지 않습니다. 가상 신규 보고서 회귀는 특정 제목에 종속되지 않는 동작을 검증하지만, 새 실제 PDF의 답변 품질 평가를 대신하지 않습니다. 이미지·표 요약 호출의 토큰은 앱의 요청 로그에 추가 수집합니다.
